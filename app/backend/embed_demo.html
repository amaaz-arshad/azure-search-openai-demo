This is exactly what you paste on a site, before the closing </body> tag. The data-chatbot-id value is an anonymous public ID — it does not reveal the chatbot's name, and it stays stable so a snippet keeps working.

Allowed domains (whitelist)

For security and licensing, each chatbot can be limited to specific pages. Edit the whitelist for the selected bot below — one rule per line. If the page the snippet is on is not on the list, the widget does not appear. Leave the list empty to allow it on any site. This is the same setting available in the Chatbot Directory (/chatbots) Embed dialog — changes from either place are saved to the same place.

Rule format

RuleMatches
(empty)Any site — the default.
*.snap.deAny subdomain of snap.de (e.g. app.snap.de); the bare snap.de is not included.
publishone.snap.deThat exact host, on any page.
publishone.snap.de/preise.htmlOnly that one page.
help.customer-website.com/*That host and every page beneath it.
A leading https:// is optional, host matching ignores capitalization, and the query string is ignored. On this page: if you give a bot a whitelist that doesn't include this address, its bubble will correctly stop appearing here.

Add it to your website

Two steps, then you're done.

  1. Copy the snippet Use the snippet shown above (or the same one in the Chatbot Directory Embed dialog). It carries the bot's anonymous public ID.
  2. Paste it just before </body> Drop the single <script> tag into your site's HTML (or your CMS's "custom HTML / footer scripts" box) on every page where the bubble should appear. Save and publish.
That's it. The bubble appears automatically on whitelisted pages. Fixes and new features are served from our backend, so the widget updates itself with no change on your end.

How the embed works

One snippet

Paste a single <script> tag before </body>. The chat bubble renders itself — no HTML, CSS, or build step.

Anonymous & gated

The snippet carries only an opaque ID, and the widget renders only on whitelisted pages — the name stays hidden and embedding stays controlled.

Fully isolated

The chat runs in an iframe, so its styles and scripts never clash with your site, and your site can't break the chat.

Auto-updates

Improvements ship from the server. You never have to change the snippet on your site again.

Resizable & responsive

Drag the popup to the size you like on desktop; on phones it expands to a comfortable near-fullscreen view.

Works when logged-in

Bots behind the simple per-chatbot login work inside the iframe over HTTPS. (Microsoft sign-in bots can't be embedded.)
